BIRTHDAY WEBSITE ❤️

1. Extract this ZIP.
2. Open index.html in Chrome/Edge.
3. All photos are already included in the photos folder.
4. To add music later, put an MP3 in the folder and add an <audio> player in index.html.

For phone sharing:
- Upload the extracted folder to any static website host, or
- Use GitHub Pages / Netlify / Vercel.
